# Dog Model

## 概要

pawverseの中心エンティティ。「キャラクター犬」を表す。

Dogは状態を保持するモデルであり、アクション実行やステータス変更ロジックは直接持たない。

振る舞いはService層へ委譲。

## 責務

Dogが責任を持つこと:

- キャラ犬の基本情報保持
- リレーション管理
- 公開状態の管理
- 初期DogStatusの生成(Modelイベント)

Dogが責任を持たないこと:

- ステータス計算
- レベルアップ処理
- クールダウン判定
- アクション実行

=> これらはService層へ委譲。

## テーブル(カラム)

| カラム     | 説明                         |
|------------|------------------------------|
| user_id    | 所有ユーザー                 |
| name       | 名前(リアル犬の名前でもある) |
| color      | 表示用カラー(カラーコード)   |
| size_level | 表示用サイズレベル(1～9)     |
| met_at     | 出会った日                   |
| is_public  | 公開状態                     |

## リレーション

- RealDog(1対1)
- DogStatus(1対1)
- DogActionLog(1対多)

---

## モデルイベント

- created: DogStatusを自動生成
- deleting: 紐づくRealDog写真削除

--- 

## 設計メモ

- Dogは状態保持に集中させる
- ビジネスロジックはServiceへ分離
