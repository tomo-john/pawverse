## 1. このリニューアルの目的

単純なCRUDアプリは別のポートフォリオで作成したので、CRUDプラスの機能を追加したい。


## 2. コンセプト(変えない軸)

- 犬をテーマにしたアプリであることは変えない
- 自分だけの相棒犬を登録する

## 3. 今回のスコープ

### やること

- アプリ構想、設計の見直し
- 不要ファイル、ディレクトリを消して綺麗にする(再利用できるものであっても学習のために作り直す)

### 一旦やらないこと・保留

## 4. 犬の飼育について

- 現状は1人1匹スタート
- 将来的に複数飼育も検討 → モデルは `User has many Dog` を見据えて設計
- 複数飼育には上限は設ける

## 5. ゲーム要素

やりたいこと: レベル・成長・遊びの概念を強くしたい

- 放置系（時間経過でステータス変化）
- お世話アクション
- ミニゲーム的な「遊ぶ」アクション

### ステータス(追加の可能性あり)

- レベル(レベルがあがるにつれて、レベルがあがりにくくなる)
- 経験値(レベルアップに必要)
- Happy(犬の感情表現などに使用)
- HP(犬の体調・空腹具合などで使用)
- 性格
