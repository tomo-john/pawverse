# DogCooldownService

## 役割

Dogアクション実行における「クールダウン制御」を担当するService。

DogActionLogの履歴を参照し、指定されたアクションが実行可能かどうかを判定。

実行不可の場合は「次に実行可能になるまでの時間(秒)」を算出する。

Dogモデルの責務外の為、Serviceとして切り分け。

## 設計意図

クールダウンはDogの状態ではなく「アクション実行のルール」。

そのため、Dogモデルにはロジックを持たず、ビジネスルールとしてService層へ分離。

=> Dogモデルはあくまで状態の保持(実行可否の判断ロジックは外部に委譲)

## 処理内容

- DogAction定義からcooldownタイムを取得
- DogActionLogから直近の同一アクションを取得
- 次回実行可能時刻を算出
- 現在時刻との差分から残り秒数を返却
- 残り時間が0秒の場合、実行可能と判断

## 呼び出し元

- DogActionService
